# 確認用サンプル

mdmielで開いて表示を確認するためのファイル。リポジトリルートで `./mdmiel docs` すると、このディレクトリもサイドバーに出る。

## CSV

| ファイル | 確認すること |
|---|---|
| notion-tasks.csv | 正常なUTF-8カンマ区切り。1行目ヘッダーの表 |
| review-issues.csv | 空ヘッダー・重複ヘッダー・列数不一致・空セルのバナーと強調 |
| quoted-fields.csv | セル内のカンマ・二重引用符・改行が1セルのまま残る |
| unclosed-quote.csv | 引用符の閉じ漏れ。表にせず理由と生テキスト |
| utf8-bom.csv | 先頭BOMを除いて表になる |

512KB超や1万行超のファイルはリポジトリに置いていない。
